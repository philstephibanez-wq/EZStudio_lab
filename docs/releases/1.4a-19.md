# 1.4a(19) — Export public dynamique PROFILE

Contexte : l'export LAB regroupait les instruments et limitait le contrat à dix catégories.

Modifications : ajout rétrocompatible des `final_assertions` individuelles, cardinalité publiée, prise en charge explicite de `metrics.final_musical_assertions` pour les extensions futures. L'ancien objet `items` reste inchangé.

Validation : contrôle de contrat statique ajouté ; exécution MAIN restant à confirmer.

Impact : export documentaire seulement ; moteurs et presets inchangés.

Limites : seules les sorties finales effectivement présentes dans les métriques publiques sont exportées ; l'exhaustivité des dimensions internes du profil n'est pas attestée. Aucun module/diagnostic scientifique transmis.
