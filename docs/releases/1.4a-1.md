# EZStudio_lab v1.4a(1) — correction du validateur VERSION

Date : 22 octobre 2026.

Incident : RuntimeException `lab_version_invalid` dans `src/Twig/LabVersionExtension.php:24` après publication de VERSION=`1.4a(0)`. Le validateur acceptait seulement `major.minor[suffixe]` et interdisait les parenthèses, bien que cette notation soit désormais contractuelle.

Correction : autoriser l'extension optionnelle `(N)` en conservant l'ancrage strict de la version. Passage à `VERSION=1.4a(1)`, premier correctif après la base `1.4a(0)`.

Pas de modification scientifique, presets, pipeline ou EZScore. Le correctif antérieur de `profile.html.twig` qui protège `ai.provider` demeure.

Installation sur MAIN uniquement :
```powershell
Set-Location H:\EZStudio_lab
git pull --ff-only origin main
if ($LASTEXITCODE -ne 0) { throw "PULL_FAILED" }
php -l src\Twig\LabVersionExtension.php
if ($LASTEXITCODE -ne 0) { throw "PHP_LINT_FAILED" }
php bin/console lint:twig templates/workbench/profile.html.twig
if ($LASTEXITCODE -ne 0) { throw "TWIG_LINT_FAILED" }
php -r 'require "vendor/autoload.php"; echo (new App\Twig\LabVersionExtension())->getGlobals()["lab_version"], PHP_EOL;'
if ($LASTEXITCODE -ne 0) { throw "VERSION_RUNTIME_FAILED" }
```

Statut : commit GitHub publié ; déploiement et test d'exécution MAIN à confirmer. Tag/release GitHub non créés.
