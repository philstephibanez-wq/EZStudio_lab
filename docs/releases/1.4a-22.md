# 1.4a(22) — Réparation du test contractuel PROFILE

Contexte : test précédent tronqué puis dupliqué, erreur PHP à la ligne 11.

Modifications : remplacement intégral par un test sans interpolation et sans contenu résiduel ; VERSION et note atomiques.

Validation : php -l exécuté localement, et exécution de contrôle sur fixture représentative. La validation réelle MAIN reste obligatoire.

Impact : test uniquement, aucun changement au service ni aux moteurs.

Limites : ce test vérifie le contrat textuel ; ne démontre pas le comportement runtime complet.
